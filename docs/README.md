# Docs

আগে তৈরি করা প্রজেক্ট নোটগুলো এখানে রাখা হয়েছে, রেফারেন্সের জন্য:

- `project_documentation_redesigned.pdf` — সম্পূর্ণ সিস্টেম ডিজাইন ও ১৯-মডিউল ডেটাবেজ ব্লুপ্রিন্ট (মূল কারিগরি ডকুমেন্টেশন)
- `module_wise_revision_notes.pdf` — মডিউল-ভিত্তিক সংক্ষিপ্ত রিভিশন নোট
- `query_concepts_note.pdf` — কুয়েরি কনসেপ্ট সংক্ষিপ্ত গাইড
- `sql_mastery_note.pdf` — বিস্তারিত SQL কনসেপ্ট + ১২০+ সমাধানসহ অনুশীলন

দ্রষ্টব্য: এই ডকুমেন্টগুলোতে ব্যাকএন্ড স্ট্যাক হিসেবে PHP/Laravel/MySQL উল্লেখ আছে
(মূল ডিজাইন আলোচনার সময়কার), কিন্তু আসল ইমপ্লিমেন্টেশন এখন Python/FastAPI/SQLAlchemy
দিয়ে হচ্ছে (`../backend/`) — টেবিল ডিজাইন, ইনডেক্স স্ট্র্যাটেজি, ক্যাশিং প্যাটার্ন
ইত্যাদি ডিজাইন-সিদ্ধান্তগুলো অপরিবর্তিত থাকবে, শুধু কোড ভাষা/ফ্রেমওয়ার্ক বদলাচ্ছে।
